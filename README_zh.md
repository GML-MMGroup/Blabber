## 💡 Blabber 是什么？

Blabber 是一个**专为播客视频创作打造的 AI 生产平台**。你不需要录音、不需要做动画、也不需要剪辑 — 只需描述你想要的节目，一支 AI Agent 团队就会编排整个制作流程：**选题策划 → 对白脚本 → 音色选角 → 语音合成 → 口型同步 → 运镜编排 → 剪辑 → 最终渲染。**

它不是"一键出片就结束"的生成器。Blabber 会把每期节目变成一个**可编辑的工程项目**：生成之后，你可以继续打磨任何细节 — 一句台词、一位主持人的音色、一个镜头切换、一处场景 — 既可以在内置的 AI Copilot 对话框里说出来，也可以直接在片段式时间线上动手改。

## ✨ 核心功能

### 1. 🎯 一句提示词 → 一整期节目
不写脚本、不录音、不打关键帧。描述主题、风格、时长和调性，系统自动生成**节目大纲、双主持对白脚本、语音演绎、口型同步动画、运镜方案和最终合成成片。**

### 2. 💬 AI Copilot — 用对话创作和修改
编辑器内嵌对话面板。直接说：*"开场再抓人一点"、"给 B 主持换个更沉稳的声音"、"加一段聊拉花的内容"* — Copilot 会重写脚本、重新配音并更新时间线，而你已经满意的部分不会被动到。

### 3. 🤖 专业 AI Agent 团队协同制作
每个制作环节都由对应的专业 Agent 负责：

| Agent | 职责 |
|-------|------|
| 🎬 **总制片** | 理解你的需求，规划节目结构、节奏与段落 |
| ✍️ **对白编剧** | 双主持对谈脚本 — 开场钩子、互动拌嘴、承转、收尾 |
| 🎙️ **配音导演** | 为每位主持人选角配音，控制情绪、语气与表达 |
| 👄 **口型引擎** | 将每个口型逐帧精准对齐音频波形 |
| 🎥 **运镜导演** | 编排镜头 — 双人全景、说话人特写、反应镜头、切换时机 |
| 🎵 **声音设计** | 片头片尾音乐、环境音、转场音效、响度平衡 |
| 🎞️ **成片合成** | 将片段、音频与字幕合成渲染为最终成片 |

### 4. 🗣️ 真实对谈，而不是轮流独白
对白引擎写出的是真正的你来我往 — 插话、附和、追问、笑声。在时间线上，两位主持人的台词以**独立音频片段交错排列，就像真实对话一样**，每个片段都可以单独编辑、重新配音或重新生成。

### 5. 👄 逐帧精准口型同步
每个音节都驱动角色的口型变化。改一句台词，动画自动重新同步 — 从此告别手动关键帧。

### 6. 🎥 自动化运镜
Blabber 像真正的节目导播一样切镜头：全景交代环境，特写对准说话人，反应镜头给到聆听者，切换节奏跟随对话的呼吸感。

### 7. 🗂️ 丰富的内置素材库
- **50+ 角色** — 风格多样的动画主持人，跨集保持形象一致
- **30+ 场景** — 演播室、温馨小屋、夜间布景、户外场景
- **60+ AI 音色** — 温暖、明亮、沉稳、活力，覆盖多语言与多年龄段

自由组合搭配；同一角色在每个镜头、每期节目中都保持视觉一致。

### 8. ✂️ 完全可编辑的片段式时间线
生成的节目落在一条**可编辑的时间线**上，而不是一个封死的视频文件。调整片段顺序、修剪台词、更换音色、切换机位、调整音乐 — 只重新渲染改动的部分。

### 9. 🔄 候选版本与历史回滚
每次重新生成都先以**候选版本**呈现 — 预览、采纳、拒绝或回滚。只有确认后的版本才会进入你的节目。

### 10. 📤 一键适配全平台
支持 16:9、9:16、1:1 导出，字幕直接烧录 — 无缝发布到 B 站、抖音、YouTube、TikTok 和视频播客平台。

## 🏗️ 工作原理
💡 提示词 → 🎬 节目策划 → ✍️ 对白脚本 → 🎙️ 语音演绎
↓
🚀 最终成片 ← 🎞️ 合成 ← 🎵 声音 ← 🎥 运镜编排 ← 👄 口型同步

全流程由 AI Agent 编排，可在内置编辑器中随时修改。
